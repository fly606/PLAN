# 绒绒计划局

安卓端优先落地的「懒人全自助计划 + 动物塑治愈激励」原生 Android App 原型。

## 已实现的演示能力

- 原生 Android Java 单 Activity，可打包为 APK。
- 多巴胺渐变背景、大圆角按钮、软弹点击反馈。
- 随机 Q 版动物陪学、每日励志弹窗、星座求签卡片。
- 今日任务清单、按权重计算进度、完成/取消打卡反馈。
- AI 懒人计划生成入口：输入任务、周期和目标量后一键加入今日清单。
- 主色系切换：蜜桃粉、晴空蓝、青草绿、香芋紫，同步导航栏和控件视觉。
- 专注计时、白噪音、休息日、数据复盘、成就系统等模块入口。

## 构建

```bash
gradle assembleDebug
```

成功后 APK 位于：

```text
app/build/outputs/apk/debug/app-debug.apk
```
